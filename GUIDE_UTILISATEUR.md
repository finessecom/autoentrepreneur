## 1. À quoi sert cette application ?

L'Auto-Entrepreneur est un espace de travail personnel qui vous permet de gérer votre activité au quotidien, sans connaissances comptables :

| Besoin | Module de l'application |
|---|---|
| Garder la liste de vos clients | **Clients** |
| Garder votre catalogue de prix | **Produits / Services** |
| Créer des devis et des factures professionnels | **Devis-Factures** |
| Générer un PDF avec votre logo et votre signature | Bouton **PDF** |
| Suivre les paiements reçus | Fiche du document, bloc **Paiement** |
| Enregistrer vos dépenses | **Charges** |
| Estimer vos impôts et la CNSS chaque trimestre | **Déclarations** |
| Voir votre chiffre d'affaires et votre résultat | **Tableau de bord** |
| Avoir une page publique de présentation | **Mon Profil → Voir profil public** |

**Important :** chaque utilisateur ne voit que ses propres données. Vos clients, factures et déclarations sont privés. Seul votre **profil public** est visible par toute personne ayant le lien.

## 2. Créer son compte

### 2.1 Ouvrir l'application

1. Ouvrez votre navigateur (Chrome, Firefox, Edge, Safari…).
2. Saisissez l'adresse de l'application : `https://autoentrepreneur.marocentreprise.com/`.
3. La page d'accueil s'affiche avec deux onglets : **Connexion** et **Inscription**.

> 💡 Une connexion Internet est nécessaire. L'application fonctionne sur ordinateur, tablette et téléphone.

### 2.2 S'inscrire

1. Cliquez sur l'onglet **Inscription**.
2. Remplissez le formulaire :

| Champ | Obligatoire | Ce qu'il faut saisir |
|---|---|---|
| **Nom complet** | Oui | Votre nom et prénom, ou le nom de votre activité (ex. `Mohamed Alami`) |
| **Email** | Oui | Une adresse email valide et durable (elle servira à vous connecter) |
| **Ville** | Non | Votre ville (ex. `Casablanca`) |
| **Mot de passe** | Oui | Au moins **6 caractères** |
| **Confirmer le mot de passe** | Oui | Le même mot de passe, sans faute de frappe |

3. Cliquez sur **Créer mon compte**.

Si tout est correct, votre compte est créé et vous êtes connecté automatiquement. Vous arrivez sur le **Tableau de bord**.

### 2.3 Erreurs possibles à l'inscription

| Message | Cause | Solution |
|---|---|---|
| « Veuillez remplir tous les champs obligatoires. » | Un champ obligatoire est vide | Vérifiez le nom, l'email et le mot de passe |
| « Les mots de passe ne correspondent pas. » | Les deux mots de passe sont différents | Retapez-les à l'identique |
| « Le mot de passe doit contenir au moins 6 caractères. » | Mot de passe trop court | Choisissez-en un plus long |
| « Adresse email invalide. » | Format d'email incorrect | Exemple correct : `nom@domaine.com` |
| Un message indique que l'email existe déjà | Un compte utilise déjà cette adresse | Connectez-vous ou utilisez une autre adresse |

> ⚠️ **Conservez précieusement votre email et votre mot de passe.** Il n'existe pas de bouton « mot de passe oublié » dans l'application. En cas d'oubli, contactez l'administrateur.

## 3. Se connecter et se déconnecter

### 3.1 Se connecter

1. Ouvrez la page d'accueil.
2. Restez sur l'onglet **Connexion**.
3. Saisissez votre **email** et votre **mot de passe**.
4. Cliquez sur **Se connecter**.

Vous arrivez sur le **Tableau de bord**.

> 🔒 Après **5 tentatives échouées en 5 minutes**, la connexion est temporairement bloquée pour votre adresse réseau. Attendez quelques minutes avant de réessayer.

### 3.2 Se déconnecter

1. En haut à droite, cliquez sur votre **nom** (menu utilisateur).
2. Cliquez sur **Déconnexion**.

Déconnectez-vous toujours si vous utilisez un ordinateur partagé.

## 4. Premiers réglages : préparer son profil

Avant de créer votre première facture, prenez **10 à 15 minutes** pour compléter votre profil. Ces informations apparaîtront sur vos PDF.

### 4.1 Accéder au profil

1. Dans le menu de gauche, cliquez sur **Mon Profil**.
2. Cliquez sur le bouton **Modifier**.

### 4.2 Renseigner vos informations personnelles

| Champ | Conseil |
|---|---|
| **Nom complet** | Obligatoire. Il apparaît sur les documents |
| **Nom d'affichage** | Nom utilisé sur votre profil public |
| **Titre professionnel (FR / AR)** | Ex. `Graphiste freelance`, `Développeur web` |
| **Ville** | Votre ville d'activité |
| **Langue principale** | Français, Arabe ou Anglais |
| **Téléphone / WhatsApp** | Vos coordonnées professionnelles |
| **Site web** | Votre site, si vous en avez un |
| **Mots-clés** | Vos compétences, séparées par des virgules (ex. `logo, identité visuelle, print`) |
| **Bio (FR / AR)** | Quelques phrases de présentation |

### 4.3 Renseigner vos informations légales

Ces champs sont **essentiels pour vos factures** :

| Champ | Où le trouver |
|---|---|
| **Raison sociale** | Nom déclaré de votre activité |
| **Email professionnel** | Adresse que vous souhaitez montrer aux clients |
| **ICE** | Identifiant Commun de l'Entreprise (15 chiffres) |
| **Identifiant fiscal (IF)** | Fourni par la Direction Générale des Impôts |
| **Nom de la banque** | Ex. `Attijariwafa Bank` |
| **RIB** | Votre numéro de compte bancaire (24 chiffres) |
| **Taxe professionnelle** | Numéro de taxe professionnelle, si vous en avez un |

> ⚠️ Un PDF sans ICE ni IF n'est pas un document professionnel complet. Vérifiez ces informations avant d'envoyer votre première facture.

### 4.4 Ajouter votre logo et votre signature

Dans la colonne de droite de la page **Modifier mon profil** :

1. **Logo (pour PDF)** : cliquez sur le champ, choisissez une image, puis enregistrez.
   - Formats acceptés : JPG, JPEG, PNG, GIF, WEBP, SVG.
2. **Signature** : même principe. Choisissez une image de votre signature (photo ou scan sur fond blanc).
3. **Taille signature** : Petite, Moyenne, Grande ou Très grande.
4. Cliquez sur **Enregistrer** en bas de la page.

> 💡 Le logo et la signature sont intégrés automatiquement aux PDF. Une signature manuscrite scannée suffit.

### 4.5 Régler les préfixes de numérotation

Toujours dans **Modifier mon profil**, section **Préfixes des documents** :

- **Préfixe Devis** : par défaut `DEV` → numéro `DEV-2026-0001`
- **Préfixe Facture** : par défaut `FAC` → numéro `FAC-2026-0001`
- **Préfixe Bon de livraison** : conservé pour compatibilité (`BL`)

Vous pouvez personnaliser ces préfixes (20 caractères maximum). Les numéros sont générés automatiquement, dans l'ordre, sans doublon.

### 4.6 Changer votre mot de passe

Dans la même page, section **Changer le mot de passe** :

1. Saisissez votre **mot de passe actuel**.
2. Saisissez le **nouveau mot de passe** (6 caractères minimum).
3. Confirmez-le.
4. Cliquez sur **Enregistrer**.

> ⚠️ Le changement de mot de passe se fait en même temps que l'enregistrement du profil. Ne modifiez pas vos autres informations par erreur pendant l'opération.

## 6. Le cycle de gestion de votre activité

Voici le parcours logique recommandé :

```
1. Profil complet (ICE, IF, RIB, logo, signature)
                ↓
2. Produits / Services (votre catalogue)
                ↓
3. Clients (les personnes à qui vous vendez)
                ↓
4. Devis (proposition) → Facture (document définitif)
                ↓
5. PDF envoyé au client
                ↓
6. Paiement reçu → statut « Payé » + détails du paiement
                ↓
7. Facture associée à un trimestre
                ↓
8. Déclaration trimestrielle (IR + CNSS)
```

En parallèle, enregistrez vos **charges** pour connaître votre résultat réel.

> 🔑 **Règle d'or :** une facture n'apparaît dans le calcul de la déclaration que si elle est **de type Facture**, avec le statut **Payé**, et si elle est **associée à une année et un trimestre**.

## 7. Gérer vos produits et services

Le catalogue vous évite de retaper vos prix à chaque facture.

### 7.1 Créer un produit ou service

1. Menu **Produits / Services**.
2. Cliquez sur **+ Nouveau Produit ou Service**.
3. Remplissez :

| Champ | Obligatoire | Détail |
|---|---|---|
| **Type d'activité** | Oui | **Commerce (Produits)** ou **Service** |
| **Désignation** | Oui | Nom de l'article ou de la prestation |
| **Détail** | Non | Description complémentaire reprise sur la facture |
| **Prix unitaire** | Oui | Montant hors taxe |
| **Devise** | Oui | MAD, EUR, USD ou GBP |
| **Image** | Non | JPG, JPEG, PNG, GIF ou WEBP |

4. Cliquez sur **Enregistrer**.

### 7.2 Pourquoi le type d'activité est important

Le type choisi sert à classer votre catalogue et à retrouver vos articles par catégorie. Il vous rappelle aussi le taux applicable :

- **Commerce (Produits)** : IR de **0,5 %** du chiffre d'affaires.
- **Service** : IR de **1 %** du chiffre d'affaires.

> ⚠️ Le taux réellement appliqué lors de la déclaration est celui du **type d'activité sélectionné dans le simulateur** (§ 13.4). Veillez à ce que les deux correspondent. Le type du catalogue ne modifie pas automatiquement la déclaration.

### 7.3 Modifier ou supprimer

- **Modifier** : icône crayon dans la liste.
- **Supprimer** : icône corbeille, avec confirmation.

Un produit déjà utilisé sur une facture peut encore être supprimé du catalogue : la ligne de facture existante conserve son texte et son prix.

## 8. Gérer vos clients

### 8.1 Créer un client

1. Menu **Clients**.
2. Cliquez sur **+ Nouveau client**.
3. Remplissez :

| Champ | Obligatoire | Détail |
|---|---|---|
| **Nom du client** | Oui | Personne ou société |
| **ICE** | Non | Recommandé pour les clients professionnels |
| **Email** | Non | Pour vos relances |
| **Téléphone** | Non | Contact |
| **Adresse** | Non | Adresse de facturation |
| **Devise** | Oui | MAD, EUR ou USD |
| **Date d'échéance** | Non | Date limite de paiement prévue |
| **Montant** | Non | Montant prévisionnel du contrat ou de la mission |

4. Cliquez sur **Enregistrer**.

> 💡 Le champ **Montant** alimente le **CA Prévisionnel** du tableau de bord. Utilisez-le pour vos devis en attente ou vos missions à venir.

### 8.2 Consulter la fiche client

Depuis la liste, cliquez sur l'icône **œil** ou sur le nom du client. La fiche affiche :

- ses coordonnées et informations légales ;
- la liste de ses **documents** (devis, factures) avec statut et montant ;
- ses **échanges** (historique de communication).

### 8.3 Tenir un journal des échanges (CRM simple)

Dans **Clients → Modifier** (ou via **Gérer** sur la fiche client) :

1. Descendez à la section **Échanges avec le client**.
2. Renseignez :
   - **Date** (par défaut aujourd'hui) ;
   - **Titre** (ex. `Appel téléphonique`, `Email envoyé`, `Réunion`) ;
   - **Document joint** (facultatif) : PDF, DOC, DOCX, XLS, XLSX, PNG, JPG — **10 Mo maximum** ;
   - **Message** : le contenu de l'échange.
3. Cliquez sur **Ajouter l'échange**.

Chaque échange peut être supprimé avec l'icône corbeille. C'est très utile pour garder une trace des relances et des accords.

### 8.4 Modifier ou supprimer un client

- **Modifier** : depuis la fiche client ou la liste.
- **Supprimer** : icône corbeille. La suppression est définitive.

> ⚠️ **Attention :** supprimer un client supprime aussi automatiquement **tous ses documents** (devis et factures) et leurs lignes. Ne supprimez jamais un client qui a un historique. En cas de doute, gardez la fiche.

## 9. Créer un devis ou une facture

### 9.1 Avant de commencer

Vérifiez que :

- votre **profil légal** est complet (ICE, IF, banque, RIB) ;
- le **client** existe dans le module Clients ;
- vos **produits/services** sont créés (facultatif, mais plus rapide).

### 9.2 Créer le document

1. Menu **Devis-Factures**.
2. Cliquez sur **+ Nouveau Devis ou Facture**.
3. Section **Informations générales** :

| Champ | Explication |
|---|---|
| **Type de document** | **Devis** (proposition) ou **Facture** (document comptable) |
| **Date** | Date du document (par défaut aujourd'hui) |
| **Statut** | **Brouillon** ou **Envoyé** (voir § 9.5) |
| **Client** | Choisissez un client existant (obligatoire) |
| **Devise** | MAD, EUR, USD ou GBP |

4. Section **Lignes d'articles** :
   - Cliquez sur **+ Ajouter une ligne**.
   - **Désignation** : texte de la ligne (obligatoire).
   - **Produit/Service** : sélectionnez un produit du catalogue pour préremplir automatiquement le prix et le détail, ou laissez **Saisie libre**.
   - **Détail** : précision complémentaire.
   - **Qté** : quantité (1 minimum).
   - **Prix unitaire** : prix hors taxe.
   - **Total ligne** : calculé automatiquement.
   - Icône **×** : supprime la ligne.

5. Le **Total HT** se met à jour automatiquement en bas du tableau.
6. Cliquez sur **Enregistrer**.

Vous êtes redirigé vers la fiche du document, qui affiche son numéro définitif.

> 💡 **Numérotation automatique :** `PREFIXE-ANNEE-0001`, par exemple `FAC-2026-0001`. Le numéro est attribué à l'enregistrement et ne change plus.

### 9.3 Devis ou facture : quelle différence ?

| | **Devis** | **Facture** |
|---|---|---|
| Rôle | Proposition de prix | Demande de paiement |
| Engagement | Aucun tant qu'il n'est pas accepté | Document comptable |
| Préfixe | `DEV` | `FAC` |
| Compte dans le CA | Non | Oui (hors annulée) |
| Compte dans la déclaration | Non | Oui, si payée et associée à un trimestre |

> ⚠️ L'application ne propose pas de bouton « convertir un devis en facture ». Si le devis est accepté, créez une **nouvelle facture** en reprenant les mêmes lignes.

### 9.4 Générer le PDF

Sur la fiche du document :

1. Cliquez sur **PDF** (bouton rouge).
2. Le PDF s'ouvre dans un nouvel onglet.
3. Utilisez les boutons de votre navigateur pour **l'imprimer** ou **le télécharger**.

Le PDF contient :

- votre logo et votre signature (si uploadés) ;
- la bannière de l'application ;
- vos informations légales : nom, raison sociale, ville, ICE, IF, banque, RIB ;
- les informations du client (nom, ICE, téléphone, email, adresse) ;
- le tableau des lignes, les quantités, les prix et le total ;
- le **montant en lettres** ;
- les mentions légales : *Art 89 – II – 1° - c du Code Général des Impôts* et *TVA non applicable, article 29 III a du CGI*.

> 💡 En tant qu'auto-entrepreneur, vous ne facturez pas la TVA. Le total HT correspond donc au montant net à payer.

### 9.5 Les statuts d'un document

| Statut | Signification | Ce que vous pouvez faire |
|---|---|---|
| **Brouillon** | Document en préparation | Modifier, PDF, associer, annuler, supprimer |
| **Envoyé** | Document transmis au client | PDF, annuler, supprimer — **plus de modification** |
| **Payé** | Paiement reçu | PDF, saisir les détails du paiement, associer à une déclaration |
| **Annulé** | Document annulé avec motif | PDF marqué « ANNULÉE », modifier le motif |

> ⚠️ **Point d'attention très important :** le bouton **Modifier** n'apparaît que pour les documents au statut **Brouillon**. Pour passer une facture à **Payé**, ouvrez-la pendant qu'elle est encore en **Brouillon**, cliquez sur **Modifier**, choisissez le statut **Payé**, puis enregistrez.
>
> Si vous passez une facture à **Envoyé** avant d'avoir encaissé, vous ne pourrez plus la modifier ni la marquer « Payé » ensuite. **Conseil :** gardez le statut **Brouillon** tant que le client n'a pas payé, et ne passez à **Payé** qu'au moment de l'encaissement.

### 9.6 Modifier un document

1. Ouvrez le document.
2. Cliquez sur **Modifier** (uniquement si statut **Brouillon**).
3. Modifiez le type, la date, le client, la devise ou les lignes.
4. Cliquez sur **Enregistrer**.

Le total et le PDF sont recalculés. Le numéro reste inchangé.

### 9.7 Annuler un document (sans le supprimer)

L'annulation est la bonne méthode pour une erreur sur un document **non payé**. Elle préserve la numérotation et laisse une trace.

1. Ouvrez le document (statut différent de **Payé**).
2. Cliquez sur **Annuler**.
3. Saisissez un **motif obligatoire** (ex. `erreur de montant`, `doublon`, `client a annulé`).
4. Cliquez sur **Enregistrer**.

Résultat :

- le document passe au statut **Annulé** ;
- il est **exclu des compteurs et du chiffre d'affaires** ;
- son numéro est conservé (aucun trou dans la numérotation) ;
- le PDF affiche un filigrane **ANNULÉE** et un encadré avec la date et le motif ;
- vous pouvez modifier le motif plus tard via **Modifier le motif**.

> ⚠️ Une facture **payée** ne peut pas être annulée. Une facture payée ne doit **jamais** être supprimée : elle fait partie de votre historique comptable et de vos déclarations. En cas d'erreur, contactez votre administrateur.

### 9.8 Supprimer un document

L'icône **corbeille** supprime définitivement le document et ses lignes.

> ⚠️ La suppression est **irréversible**. Utilisez-la uniquement pour un brouillon créé par erreur. Pour tout autre cas, préférez **Annuler**.

### 9.9 Filtrer et rechercher

Dans **Devis-Factures** :

- choisissez **Tous les types**, **Devis** ou **Facture** ;
- saisissez un nom de client dans **Rechercher par client** ;
- cliquez sur **Filtrer**.

Le tableau affiche : référence, date, client, désignation, montant, paiement, statut et actions (voir, PDF, modifier, supprimer).

## 10. Enregistrer un paiement

Une facture doit être au statut **Payé** pour que le bloc de paiement apparaisse.

### 10.1 Marquer la facture comme payée

1. Ouvrez la facture encore au statut **Brouillon**.
2. Cliquez sur **Modifier**.
3. Dans **Statut**, choisissez **Payé**.
4. Cliquez sur **Enregistrer**.

### 10.2 Saisir les détails du paiement

Sur la fiche de la facture payée, un bloc **Paiement** apparaît :

1. **Date paiement** : date à laquelle l'argent a été reçu.
2. **Montant (DH)** : montant encaissé (prérempli avec le total).
3. **Mode de paiement** : Espèces, Virement, Cashplus, TapTapSend ou Autres.
4. Cliquez sur **Enregistrer le paiement**.

> 💡 Le montant payé alimente le **Total montant payé** de la liste et le **CA Réalisé** du tableau de bord. Saisissez-le systématiquement pour un suivi fiable.

> ⚠️ L'application gère **un seul paiement par facture**. Pour un paiement partiel, saisissez le montant réellement reçu ; le solde restant n'est pas suivi automatiquement.

## 11. Associer une facture à une déclaration

Cette étape est **indispensable** pour que vos factures apparaissent dans le simulateur de déclaration.

### 11.1 Procédure

1. Ouvrez la **facture** (elle doit être au statut **Payé**).
2. Descendez au bloc **Déclaration fiscale**.
3. Renseignez :
   - **Année** : ex. `2026` ;
   - **Trimestre** : T1, T2, T3 ou T4 ;
   - **Total facture (MAD)** : montant à prendre en compte dans la déclaration (prérempli avec le total).
4. Cliquez sur **Enregistrer**.

Un message confirme : *« Associé à la déclaration T4 2026 »*.

### 11.2 Règles à retenir

- Seules les **factures** (pas les devis) sont prises en compte.
- La facture doit être au statut **Payé**.
- La facture doit avoir une **année** et un **trimestre**.
- Pour le calcul de la déclaration, pensez à saisir le **Total facture (MAD)**. L'application **ne convertit pas automatiquement** les devises : si vous facturez en EUR, USD ou GBP, indiquez vous-même l'équivalent en dirhams dans ce champ.

> 💡 Prenez l'habitude d'associer chaque facture payée à son trimestre **au moment de l'encaissement**. Vous éviterez les oublis en fin de trimestre.

## 12. Enregistrer vos charges

Les charges sont vos dépenses professionnelles : loyer, matériel, logiciels, déplacements, fournitures, etc.

### 12.1 Ajouter une charge

1. Menu **Charges**.
2. Cliquez sur **+ Nouvelle charge**.
3. Remplissez :

| Champ | Obligatoire | Détail |
|---|---|---|
| **Date** | Oui | Date de la dépense (par défaut aujourd'hui) |
| **Désignation** | Oui | Ex. `Achat fournitures`, `Loyer bureau`, `Abonnement logiciel` |
| **Montant EUR** | Non | Si la dépense est en euros |
| **Montant MAD** | Oui | Montant en dirhams |

4. Cliquez sur **Enregistrer**.

### 12.2 Utilisation

- Le **total des charges en MAD** apparaît sur le tableau de bord.
- Le **Résultat** du tableau de bord est calculé ainsi : **CA Prévisionnel − Charges**.
- Les charges ne sont pas automatiquement liées à la déclaration fiscale ; elles servent à votre suivi de gestion.

> 💡 Enregistrez vos charges au fil de l'eau, pas à la fin de l'année. Gardez les justificatifs (reçus, factures) de votre côté.

## 13. Faire votre déclaration trimestrielle

### 13.1 Principe

L'application vous aide à **estimer** et à **archiver** votre déclaration trimestrielle. Elle ne déclare rien à votre place auprès de la DGI.

Le simulateur s'appuie sur :

- les **factures payées** associées au trimestre sélectionné ;
- le **type d'activité** (taux d'IR) ;
- la **tranche CNSS** choisie ;
- les **pénalités et frais** éventuels ;
- la **retenue à la source** éventuelle.

### 13.2 Avant de commencer

1. Vérifiez que toutes les factures du trimestre sont au statut **Payé**.
2. Vérifiez qu'elles sont associées au bon **trimestre** et à la bonne **année** (§ 11).
3. Vérifiez que les montants en MAD sont corrects.

### 13.3 Ouvrir le simulateur

1. Menu **Déclarations**.
2. Cliquez sur **+ Nouvelle déclaration**.

### 13.4 Sélectionner la période et l'activité

En haut de l'écran :

1. **Année** : choisissez l'année concernée.
2. **Trimestre** : T1, T2, T3 ou T4.
3. **Type d'activité** :
   - **Services** → taux IR 1 % ;
   - **Produits / Commerce** → taux IR 0,5 % ;
   - **Tous** → applique le taux **Services**.

> ⚠️ Si vous vendez des produits, sélectionnez bien **Produits / Commerce**. Laisser **Tous** appliquerait le taux de 1 % au lieu de 0,5 %.

Les cartes se mettent à jour :

- **Factures** : nombre, liste des références et total ;
- **CNSS** : tranche et montant ;
- **Pénalités et frais** : champs modifiables ;
- **Calcul automatique** : récapitulatif.

### 13.5 Choisir la tranche CNSS

La cotisation CNSS dépend de votre chiffre d'affaires trimestriel :

| Tranche | CA trimestriel | Montant trimestriel |
|---|---|---|
| **T0** | Gratuit | 0 DH |
| **T1** | 0 – 499 DH | 300 DH |
| **T2** | 500 – 1 000 DH | 390 DH |
| **T3** | 1 001 – 2 500 DH | 570 DH |
| **T4** | 2 501 – 5 000 DH | 720 DH |
| **T5** | 5 001 – 10 000 DH | 1 050 DH |
| **T6** | 10 001 – 25 000 DH | 1 500 DH |
| **T7** | 25 001 – 50 000 DH | 2 250 DH |
| **T8** | Plus de 50 000 DH | 3 600 DH |

Sélectionnez la tranche dans la carte **CNSS**. Le montant est repris dans le calcul.

### 13.6 Saisir les pénalités et frais

Si vous êtes en retard ou si vous avez des frais particuliers :

1. Saisissez **Pénalités (MAD)**.
2. Saisissez **Frais (MAD)**.
3. Le total se met à jour.

> 💡 En cas de retard, l'usage courant est d'appliquer **10 % par mois de retard entamé**. Saisissez ce montant vous-même dans **Pénalités** : l'application ne le calcule pas automatiquement à votre place. Ce calcul reste indicatif.
>
> ⚠️ Les champs **Pénalités** et **Frais** servent à l'estimation affichée à l'écran. Ils ne sont pas conservés dans l'enregistrement de la déclaration : notez leur montant de votre côté si vous devez les déclarer.

### 13.7 Remplir la déclaration

Section **Déclaration** :

- **Réf. déclaration** : votre référence (ex. `DECL-2026-T4`) ;
- **Date déclaration** : date de dépôt ;
- cochez **Déjà déclaré** si la déclaration a été effectuée auprès de la DGI.

Section **Paiement** :

- **Réf. paiement** : référence de votre paiement (ex. `PAI-001`) ;
- **Date paiement** ;
- **Mode de paiement** : Espèces, Virement, Cashplus, TapTapSend, Autres ;
- cochez **Déjà payé** si vous avez réglé l'impôt et la CNSS.

Cliquez sur **Enregistrer la déclaration**.

> ⚠️ **Point d'attention :** le bloc **Calcul automatique** affiche une estimation à l'écran (base factures + CNSS + pénalités/frais). Le montant enregistré est recalculé par l'application à partir de l'**IR + CNSS + retenue à la source**. Après l'enregistrement, vérifiez toujours le récapitulatif dans la liste des déclarations. En cas de doute, fiez-vous à votre comptable ou à la DGI.

### 13.8 Comprendre les montants

| Élément | Calcul |
|---|---|
| **IR Commerce** | 0,5 % du CA commerce, plafonné à 500 000 DH de CA |
| **IR Service** | 1 % du CA service, plafonné à 200 000 DH de CA |
| **CNSS** | Montant fixe de la tranche choisie |
| **Retenue à la source (RAS)** | 30 % si le CA annuel chez un même client dépasse 80 000 DH |
| **Total** | IR + CNSS + RAS |

> 💡 Le formulaire de création ne contient pas de champ RAS dédié. Si votre client applique une retenue à la source, enregistrez la déclaration, puis ouvrez-la avec l'icône **Modifier** pour saisir le montant dans **Retenue source**.

### 13.9 Activité mixte (commerce + service)

Le formulaire de création demande de choisir **un** type d'activité. Si vous avez les deux :

1. Enregistrez d'abord la déclaration avec votre activité principale.
2. Ouvrez ensuite la déclaration via **Modifier**.
3. Renseignez **CA Commerce** et **CA Service** séparément.
4. Enregistrez : l'IR est recalculé pour chaque partie.

> 💡 Une seule déclaration existe par année et par trimestre. La modification met à jour la déclaration existante.

### 13.10 Les échéances

| Trimestre | Période | Date limite indicative |
|---|---|---|
| **T1** | Janvier – Février – Mars | **30 avril** |
| **T2** | Avril – Mai – Juin | **31 juillet** |
| **T3** | Juillet – Août – Septembre | **31 octobre** |
| **T4** | Octobre – Novembre – Décembre | **31 janvier** de l'année suivante |

> ⚠️ Ces dates sont indicatives. Vérifiez toujours les échéances officielles auprès de la DGI.

### 13.11 Consulter et modifier vos déclarations

Dans **Déclarations** :

- filtrez par **année** ;
- consultez le tableau : trimestre, CA, IR, CNSS, RAS, total à payer, factures associées, déclaré oui/non ;
- cliquez sur l'icône **crayon** pour modifier ;
- cliquez sur l'icône **corbeille** pour supprimer (avec confirmation).

> ⚠️ La suppression d'une déclaration ne supprime pas les factures. Elle supprime seulement l'enregistrement de la déclaration.

### 13.12 Avertissement légal

L'outil de déclaration est **uniquement indicatif**. La responsabilité de la déclaration auprès de la DGI et de la CNSS vous incombe entièrement. Les calculs reposent sur des barèmes généraux et peuvent ne pas refléter votre situation exacte. En cas de doute, consultez un comptable ou les services concernés.

## 16. Exemple concret de A à Z

**Situation :** vous êtes graphiste freelance. Un client vous demande un logo pour **3 000 MAD**.

### Étape 1 — Compléter le profil (une seule fois)

- ICE, IF, banque, RIB ;
- logo et signature ;
- préfixe facture `FAC`.

### Étape 2 — Créer le service

- Menu **Produits / Services → + Nouveau**.
- Type : **Service**.
- Désignation : `Création de logo`.
- Prix unitaire : `3000`.
- Devise : `MAD`.
- Enregistrer.

### Étape 3 — Créer le client

- Menu **Clients → + Nouveau client**.
- Nom : `Atlas SARL`.
- ICE : renseigné.
- Email et téléphone : renseignés.
- Devise : `MAD`.
- Montant : `3000` (pour le prévisionnel).
- Enregistrer.

### Étape 4 — Créer le devis

- Menu **Devis-Factures → + Nouveau**.
- Type : **Devis**.
- Client : `Atlas SARL`.
- Ligne : sélectionner `Création de logo` → prix prérempli à 3 000.
- Enregistrer.
- Télécharger le **PDF** et l'envoyer au client.

### Étape 5 — Créer la facture

Une fois le devis accepté :

- Menu **Devis-Factures → + Nouveau**.
- Type : **Facture**.
- Client : `Atlas SARL`.
- Ligne : `Création de logo`, quantité 1, prix 3 000.
- Statut : **Brouillon**.
- Enregistrer.
- Télécharger le **PDF** et l'envoyer.

La référence est par exemple `FAC-2026-0001`.

### Étape 6 — Enregistrer le paiement

Le client paie par virement :

1. Ouvrir la facture.
2. **Modifier** → statut **Payé** → enregistrer.
3. Dans le bloc **Paiement** : date, montant `3000`, mode `Virement`.
4. Enregistrer le paiement.

### Étape 7 — Associer à la déclaration

1. Sur la même facture, bloc **Déclaration fiscale**.
2. Année : `2026`.
3. Trimestre : le trimestre correspondant à la date de la facture.
4. Total : `3000`.
5. Enregistrer.

### Étape 8 — En fin de trimestre

1. Menu **Déclarations → + Nouvelle déclaration**.
2. Choisir l'année, le trimestre et **Services**.
3. Vérifier que la facture `FAC-2026-0001` apparaît.
4. Choisir la tranche CNSS correspondant au CA du trimestre.
5. Renseigner les références de déclaration et de paiement.
6. Enregistrer.

### Étape 9 — Suivre les charges

- Menu **Charges → + Nouvelle charge**.
- Exemple : `Abonnement logiciel`, 200 MAD.
- Enregistrer.

Le tableau de bord vous montre alors votre activité et votre résultat.

## 17. Bonnes pratiques et routine

### 17.1 Chaque jour ou chaque vente

- [ ] Créer la facture dès la prestation terminée.
- [ ] Vérifier le client, la date, la devise et les lignes.
- [ ] Générer le PDF et l'envoyer.
- [ ] Noter l'échange dans la fiche client (email, appel, accord).

### 17.2 À chaque paiement reçu

- [ ] Passer la facture au statut **Payé**.
- [ ] Saisir la date, le montant et le mode de paiement.
- [ ] Associer la facture au bon trimestre.
- [ ] Archiver le PDF et le justificatif de paiement.

### 17.3 Chaque semaine

- [ ] Enregistrer les charges de la semaine.
- [ ] Vérifier les devis en attente.
- [ ] Relancer les factures impayées (via les échanges).

### 17.4 Chaque fin de trimestre

- [ ] Vérifier que toutes les factures du trimestre sont **Payé** et associées.
- [ ] Vérifier les montants en MAD.
- [ ] Créer la déclaration dans le simulateur.
- [ ] Vérifier la tranche CNSS.
- [ ] Enregistrer les références de déclaration et de paiement.
- [ ] Conserver une copie du récapitulatif et des justificatifs.
- [ ] Respecter la date limite (30 avril, 31 juillet, 31 octobre, 31 janvier).

### 17.5 Chaque année

- [ ] Vérifier vos informations légales (ICE, IF, RIB, banque).
- [ ] Mettre à jour vos préfixes si nécessaire.
- [ ] Archiver vos PDF et déclarations.
- [ ] Vérifier votre plafond de chiffre d'affaires.

### 17.6 Règles de sécurité

- [ ] Ne partagez jamais votre mot de passe.
- [ ] Déconnectez-vous sur un poste partagé.
- [ ] Utilisez un mot de passe unique, de 8 caractères ou plus si possible.
- [ ] Vérifiez que la connexion se fait en **HTTPS** (cadenas dans le navigateur).
- [ ] Sauvegardez régulièrement vos PDF importants.

## 18. Problèmes fréquents (FAQ)

### Je n'arrive pas à me connecter

- Vérifiez l'email et le mot de passe (majuscules, espaces).
- Après 5 échecs en 5 minutes, attendez quelques minutes.
- Si le problème persiste, contactez l'administrateur : il n'y a pas de réinitialisation automatique.

### J'ai oublié mon mot de passe

L'application ne propose pas de lien de réinitialisation. Contactez l'administrateur pour qu'il vous aide à retrouver l'accès.

### Mon email est déjà utilisé

Un compte existe déjà avec cette adresse. Connectez-vous avec cet email ou utilisez une autre adresse.

### Je ne peux plus modifier ma facture

Le bouton **Modifier** n'apparaît que pour les documents au statut **Brouillon**. Si vous avez choisi **Envoyé**, la modification n'est plus possible. Pour une facture non payée, vous pouvez l'**annuler** avec un motif. Pour une facture payée, ne la supprimez pas : contactez l'administrateur.

### Je ne peux pas annuler ma facture

L'annulation est impossible pour une facture **Payé**. C'est volontaire : un document payé doit rester dans l'historique. Contactez l'administrateur en cas d'erreur.

### Ma facture n'apparaît pas dans la déclaration

Vérifiez les trois conditions :

1. C'est bien une **facture** (pas un devis).
2. Son statut est **Payé**.
3. Elle est associée à une **année** et un **trimestre** dans le bloc **Déclaration fiscale**.

Vérifiez aussi que le **Total facture (MAD)** est correct : l'application ne convertit pas automatiquement les devises étrangères.

### Le total de la déclaration me paraît étrange

Le bloc **Calcul automatique** du simulateur affiche une estimation (base factures + CNSS + pénalités/frais). Le montant réellement enregistré est recalculé par l'application (IR + CNSS + retenue à la source). Après enregistrement, consultez la liste des déclarations pour voir le montant retenu. En cas de doute, vérifiez avec un comptable ou la DGI.

### Le type d'activité « Tous » me donne un taux de 1 %

C'est normal : l'option **Tous** applique le taux **Services**. Si vous vendez des produits, sélectionnez **Produits / Commerce** pour bénéficier de 0,5 %.

### Mon logo ou ma signature n'apparaît pas sur le PDF

- Vérifiez que l'image est bien uploadée dans **Mon Profil → Modifier**.
- Formats acceptés : JPG, JPEG, PNG, GIF, WEBP, SVG.
- Enregistrez le profil après l'upload.
- Régénérez le PDF : il est recréé à chaque clic.

### Le montant en lettres est incorrect

Vérifiez le total de la facture et la devise. Le montant en lettres est généré automatiquement à partir du **total HT**. Si une ligne est erronée, corrigez-la et régénérez le PDF.

### Je ne vois pas mes données

Chaque compte est isolé. Vérifiez que vous êtes connecté avec le bon email. Si vous avez plusieurs comptes, les données ne sont pas partagées.

### J'ai supprimé un document par erreur

La suppression est définitive et il n'y a pas de corbeille de récupération. Contactez l'administrateur au plus vite : il peut intervenir directement en base si une sauvegarde existe.

### Le tableau de bord affiche 0 alors que j'ai des factures

- Le **CA Réalisé** dépend des factures et des paiements enregistrés.
- Le **CA Prévisionnel** dépend du champ **Montant** des fiches clients.
- Vérifiez que les documents ne sont pas annulés.
- Vérifiez que vous êtes sur le bon compte.

### Puis-je travailler avec des devises étrangères ?

Oui : MAD, EUR, USD et GBP pour les documents. Pour la déclaration, le calcul du CA par activité utilise les montants en **MAD**. Pensez à renseigner le **Total facture (MAD)** lors de l'association à la déclaration.

### Puis-je envoyer la facture par email depuis l'application ?

Non. L'application génère un PDF ; vous l'envoyez ensuite avec votre messagerie habituelle.

## 19. Glossaire

| Terme | Définition |
|---|---|
| **Auto-entrepreneur** | Statut simplifié pour exercer une activité indépendante au Maroc, avec un plafond de chiffre d'affaires |
| **Devis** | Proposition de prix avant la réalisation d'une prestation |
| **Facture** | Document demandant le paiement d'une prestation ou d'un produit |
| **Brouillon** | Document en préparation, encore modifiable |
| **Envoyé** | Document transmis au client |
| **Payé** | Paiement reçu |
| **Annulé** | Document invalidé avec un motif, conservé pour la traçabilité |
| **HT** | Hors taxe |
| **TTC** | Toutes taxes comprises (ici identique au HT, car pas de TVA) |
| **TVA** | Taxe sur la valeur ajoutée — non applicable aux auto-entrepreneurs |
| **ICE** | Identifiant Commun de l'Entreprise |
| **IF** | Identifiant Fiscal |
| **RIB** | Relevé d'Identité Bancaire |
| **IR** | Impôt sur le Revenu |
| **CNSS** | Caisse Nationale de Sécurité Sociale |
| **RAS** | Retenue à la source |
| **Trimestre** | Période de trois mois : T1 (janv.-mars), T2 (avr.-juin), T3 (juil.-sept.), T4 (oct.-déc.) |
| **CA** | Chiffre d'affaires |
| **MAD / DH** | Dirham marocain |
| **DGI** | Direction Générale des Impôts |

## 20. Ce que l'application ne fait pas

Pour éviter toute confusion, voici les limites actuelles :

- ❌ Pas d'envoi automatique de factures par email.
- ❌ Pas de conversion automatique d'un devis en facture.
- ❌ Pas de TVA (les auto-entrepreneurs n'en facturent pas).
- ❌ Pas de paiements en ligne ni de relances automatiques.
- ❌ Pas de gestion de stock.
- ❌ Pas de factures récurrentes.
- ❌ Pas de réinitialisation de mot de passe en libre-service.
- ❌ Pas de déclaration automatique auprès de la DGI ou de la CNSS.
- ❌ Pas d'export comptable (seulement le PDF).
- ❌ Pas de plusieurs utilisateurs sur un même compte.
